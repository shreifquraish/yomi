# تطبيق يومي (Yomi) - تطبيق إدارة الملاحظات والمهام

## 📱 نبذة عن التطبيق

**يومي** هو تطبيق جوال ذكي مبني باستخدام **Flutter** يساعد المستخدمين على تنظيم حياتهم اليومية من خلال:
- ✍️ حفظ الملاحظات الشخصية
- ✅ إدارة قوائم المهام اليومية
- 🔐 مصادقة آمنة باستخدام حسابات Google
- ☁️ مزامنة البيانات عبر السحابة

التطبيق يجمع بين سهولة الاستخدام والوظائف القوية لضمان تجربة مستخدم فريدة.

---

## 🎯 المميزات الرئيسية

| الميزة | الوصف |
|--------|--------|
| **تسجيل الدخول الآمن** | تسجيل دخول سريع وآمن باستخدام حساب Google |
| **عرض الملاحظات** | قائمة منظمة تعرض أحدث الملاحظات أولاً |
| **إضافة ملاحظات** | إنشاء ملاحظات جديدة بسهولة |
| **تعديل وحذف** | تحرير أو حذف الملاحظات القديمة |
| **حفظ محلي** | تخزين البيانات محلياً باستخدام SQLite |
| **قاعدة بيانات سحابية** | مزامنة البيانات مع Firebase Realtime Database |

## 🛠️ المتطلبات التقنية

### البيئة المطلوبة
- ✅ **Flutter SDK** (الإصدار 3.4.4 أو أحدث)
- ✅ **Android Studio** أو أي محرر نصوص متقدم
- ✅ **Android Emulator** أو جهاز أندرويد فعلي
- ✅ **حساب Google Firebase** (مجاني)

### الحزم الرئيسية المستخدمة
```yaml

firebase_auth: ^6.4.0          # المصادقة

sqflite: ^2.3.3+1              # قاعدة البيانات المحلية
provider: ^6.1.5+1             # إدارة الحالة
google_fonts: ^6.3.0           # الخطوط
intl: ^0.19.0                  # دعم اللغات
```

1. **تسجيل الدخول**: يقوم المستخدم بالضغط على زر "Login with Google"
2. **عرض الملاحظات**: يتم عرض جميع الملاحظات المحفوظة مرتبة بالأحدث
3. **إضافة ملاحظة**: يمكن إضافة ملاحظة جديدة من خلال زر "+"
4. **تعديل/حذف**: الضغط على أي ملاحظة يسمح بتعديلها أو حذفها
5. **المزامنة**: تتم مزامنة البيانات تلقائياً مع Firebase

## 🔥 إعداد Firebase وربطه بالتطبيق

### المرحلة 1️⃣: إنشاء مشروع Firebase

1. اذهب إلى [Firebase Console](https://console.firebase.google.com/)
2. اضغط على **"Add project"** (إضافة مشروع)
3. أدخل اسم المشروع (مثلاً: "Yomi App")
4. اختر **الدول المطبقة** (يفضل القريبة من المستخدمين)
5. اضغط **"Create Project"**

### المرحلة 2️⃣: تفعيل الخدمات المطلوبة

بعد إنشاء المشروع:

#### ✅ تفعيل Firebase Authentication
1. في القائمة اليسرى → **Build** → **Authentication**
2. اضغط **"Get Started"**
3. اختر **"Google"** من قائمة خيارات تسجيل الدخول
4. فعّل **Google Sign-in**
5. أضف بريد **دعم المشروع** (قد يكون بريد Google الخاص بك)
6. احفظ التغييرات

#### ✅ إنشاء Realtime Database
1. في القائمة اليسرى → **Build** → **Realtime Database**
2. اضغط **"Create Database"**
3. اختر **الموقع الجغرافي** الأقرب
4. اختر **"Start in test mode"** (للتطوير - غير آمن للإنتاج)
5. اضغط **"Enable"**

### المرحلة 3️⃣: ربط Android

#### 1️⃣ الحصول على SHA-1 Fingerprint

افتح Terminal في مجلد المشروع وشغّل:

```bash
# للـ Debug Key
./gradlew signingReport

# أو استخدم keytool مباشرة
keytool -list -v -keystore ~/.android/debug.keystore -alias androiddebugkey -storepass android -keypass android
```

ستجد رقم SHA-1 بهذا الشكل:
```
SHA1: XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX:XX
```

#### 2️⃣ إضافة Android إلى Firebase

1. في Firebase Console → إعدادات المشروع ⚙️
2. اضغط **"Add app"** → اختر **Android**
3. ملأ البيانات:
   - **Android Package Name**: `com.example.yomi` (أو الاسم الفعلي في `android/app/build.gradle`)
   - **App nickname**: `Yomi Android`
   - **SHA-1**: الرقم الذي حصلت عليه أعلاه
4. اضغط **"Register app"**

#### 3️⃣ تحميل ملف الإعدادات

1. حمّل ملف `google-services.json` من Firebase
2. انسخه إلى: `android/app/`
3. تأكد أن ملف `android/build.gradle` يحتوي على:

```gradle
buildscript {
  dependencies {
    classpath 'com.google.gms:google-services:4.4.0'
  }
}
```

4. وأن ملف `android/app/build.gradle` يحتوي على:

```gradle
apply plugin: 'com.google.gms.google-services'
```

### المرحلة 4️⃣: ربط iOS (اختياري)

#### 1️⃣ إضافة iOS إلى Firebase
1. في Firebase Console → **Add app** → اختر **iOS**
2. ملأ البيانات:
   - **Bundle ID**: من `ios/Runner.xcodeproj`
   - **App nickname**: `Yomi iOS`
3. حمّل ملف `GoogleService-Info.plist`

#### 2️⃣ إضافة الملف للمشروع
1. افتح `ios/Runner.xcworkspace`
2. انسخ ملف `GoogleService-Info.plist` إلى مجلد `Runner`
3. تأكد من الإضافة مع **iOS targets**

## 🚀 كيفية عمل التطبيق بعد ربط Firebase

### عند تشغيل التطبيق:

```
[1] المستخدم ينقر "Login with Google"
         ↓
[2] Firebase Authentication يتحقق من الهوية
         ↓
[3] تسجيل الدخول ناجح
         ↓
[4] تحميل الملاحظات من Realtime Database ☁️
         ↓
[5] حفظ الملاحظات محلياً في SQLite 📱
         ↓
[6] عرض الملاحظات في الواجهة
         ↓
[7] عند إضافة/تعديل ملاحظة:
     • حفظ محلي فوري ⚡
     • مزامنة مع Firebase 🔄
     • تحديث جميع الأجهزة تلقائياً 📲
```

### ميزات المزامنة:

- ✅ **المزامنة الفورية**: أي تغيير يُحفظ تلقائياً
- ✅ **العمل بدون اتصال**: البيانات تعمل حتى بدون إنترنت
- ✅ **التزامن عند الاتصال**: عند العودة للإنترنت، يتم المزامنة فوراً
- ✅ **الأمان**: كل مستخدم يرى فقط ملاحظاته الخاصة

## 📋 تعليمات الأمان والإعدادات

### قواعد Firebase Security Rules

بعد إعداد قاعدة البيانات، غيّر قواعد الأمان إلى:

```json
{
  "rules": {
    "users": {
      "$uid": {
        ".read": "$uid === auth.uid",
        ".write": "$uid === auth.uid",
        "notes": {
          ".indexOn": ["timestamp"]
        }
      }
    }
  }
}
```

هذا يضمن أن كل مستخدم يرى فقط بيانته الخاصة.

### تغيير SHA-1 Key (عند التوقيع)

عند توقيع التطبيق للإنتاج:
1. احصل على SHA-1 للـ Release Key
2. أضفه في Firebase Console → Project Settings
3. قم بـ rebuild وإعادة توقيع

## 🐛 استكشاف الأخطاء الشائعة

| المشكلة | الحل |
|--------|------|
| **Google Sign-in يفشل** | تحقق من SHA-1 الصحيح وأنه مطابق في Firebase |
| **لا توجد اتصالات في Realtime Database** | تأكد من قواعس الأمان وأنك مسجل دخول |
| **الملاحظات لا تُحفظ** | تحقق من أن ملف `google-services.json` في المكان الصحيح |
| **خطأ Flutter pub get** | شغّل `flutter clean` ثم `flutter pub get` مجدداً |
