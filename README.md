# تطبيق يومي (Youmi)

تطبيق أندرويد بسيط لحفظ الملاحظات الشخصية وقوائم المهام اليومية، تم برمجته باستخدام Flutter.

## المميزات
- تسجيل الدخول باستخدام حساب Google.
- عرض قائمة الملاحظات مرتبة بالأحدث.
- إضافة ملاحظة جديدة.
- تعديل أو حذف ملاحظة سابقة.
- تم حفظ البيانات محلياً في قاعدة البيانات (SQLite).

## متطلبات التشغيل
- Flutter SDK.
- Android Studio / Android Emulator أو جهاز أندرويد حقيقي للتجربة.
- في حالة تغيير مفاتيح التوقيع (Keystore)، ستحتاج لإضافة الـ SHA-1 الجديد إلى إعدادات مشروع Firebase.
*(الـ SHA-1 الحالي للجهاز هو `1A:8E:FF:81:6A:DF:D0:A2:D3:D0:F6:0C:B7:1E:DF:F0:ED:D3:4E:26`)*

## طريقة التشغيل

1. قم بفتح سطر الأوامر (Terminal) في مجلد المشروع.
2. تأكد من تحميل جميع الحزم بتنفيذ الأمر:
```bash
flutter pub get
```
3. قم بتشغيل التطبيق على الهاتف المتصل أو المحاكي باستخدام الأمر:
```bash
flutter run
```

## التجهيزات التقنية
- **قاعدة البيانات:** استخدمت حزمة `sqflite`.
- **إدارة الحالة:** استخدمت حزمة `provider`.
- **المصادقة:** استخدمت `firebase_auth` و `google_sign_in`.
- **الألوان والتصميم:** متوافقة تماماً مع الألوان (أزرق هادئ `#4F6DCE`، رمادي، وغيره) واستخدام خط `Cairo`.
